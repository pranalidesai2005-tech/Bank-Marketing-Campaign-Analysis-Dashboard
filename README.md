# Bank Marketing Campaign Analysis Dashboard

## Project Overview

This Power BI dashboard analyzes customer behavior, marketing campaign performance, and subscription trends using the Bank Marketing dataset.

## Dashboard Pages

### Overview
- Total Customers
- Subscription Rate
- Average Balance
- Call Duration
- Monthly Subscription Trend

### Customer Analysis
- Age Group Analysis
- Education Distribution
- Marital Status
- Loan Analysis

### Campaign Analysis
- Campaign Performance
- Contact Month Analysis
- Previous Campaign Outcome
- Call Duration Analysis

### Key Influencers
- Factors influencing customer subscription
- Housing Loan Impact
- Personal Loan Impact
- Customer Segmentation

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Dataset

Bank Marketing Dataset (UCI/Kaggle)
